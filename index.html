Billing Rules

① Free Time = CLD + 3 days (4 days incl. CLD)

⑪ Levy added without VAT
⑫ Landing/Removal/Hoisting auto-computed
⑬ Part Billing: Slab progression never resets — only weight changes per stage
⑭ Self Drive (Hoisting ✓): SD tons billed at Car Billing rates — old/new split applies at 23/07/2024

Billing Rules

① Port Side: Re-export date ≤ CLD date → validation error
② Port Side: Re-export date within 20-day free period → Wharf Rent = 0
③ Port Side: Removal ton = 0 → Removal row skipped
④ Overside → CLD not required, no Wharf Rent, no Removal, Hoisting off by default
⑤ Hoisting unchecked → Hoisting row skipped (both types)
⑥ Port Side: multiple CLD dates per Bill of Entry → each Wharf Rent calculated separately; slab uses SUM of all CLD tons
⑦ Same vs Different Wharf → affects Re-Shipment % only; Removal stays 7× (Port Side)
⑧ VAT always applies — excludes Levy
⑨ Levy unchecked (default) → Levy row skipped
⑩ Levy checked adds Tk 1.50/ton after VAT — rates editable by Admin only
